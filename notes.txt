Looking at the PE structure...

    PE Signature

    Optional Header
        Standard Fields

        Data Directories

So the COFF/Image file header needs to contain the size of the optional header, the characteristics (I think), and perhaps the machine type. More than that, I am not sure.

Import directory table:
The entries are so-called "import directory entries"
One import directory entry is present per DLL that is referred to. 
Each directory (i.e. table row) has size of 0x14 and contains:
    RVA of the import lookup table for *THIS* DLL (OriginalFirstThunk)
    Time/Date stamp (which is 0 until image bound)
    Forwarder Chain (honestly no clue, but just set to 0 ig)
    RVA of DLL name
    RVA of import address table (FirstThunk)
So iatbl gets patched with addresses by loader, but initially in standard configuration contains the same contents as the import lookup table
The import lookup table is a list of all imports where each import is given RVA data if needed, or else an ordinal.
